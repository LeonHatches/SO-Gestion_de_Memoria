# Gestor de memoria principal

Simulador educativo de RAM con Python 3. Ejecuta desde esta carpeta:

    python main.py

Opción 2 muestra la RAM. Cada punto es una posición libre. El espacio
empieza con 32 posiciones y se puede cambiar con:

    python main.py --capacidad 16

Para comprobar la RAM y el mapa:

    python -m unittest pruebas -v
